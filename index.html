設定

端末間の同期（GitHub Gist）

設定すると、どれか1台で対応表・スコア・定数表データを読み込んだときに、自動であなたのGitHubのGist（クラウド）へ保存されます。他の端末ではツールを開いたときに最新版を取り込みます。各端末で1回だけトークンを貼り付けてください。

トークンの作り方（最初の1回だけ）
  1. PCで GitHub のトークン設定 を開く（右上アイコン → Settings → Developer settings → Personal access tokens → Tokens (classic)）
  2. 「Generate new token」→「Generate new token (classic)」
  3. Note に「chuni-sync」など、Expiration は「No expiration」（または1年）、スコープは gist だけにチェック
  4. 「Generate token」→ 表示された ghp_… をコピー（この画面でしか表示されないので、メモアプリ等に控えておく）

トークンはこの端末のブラウザにだけ保存され、GitHub以外には送られません。パスワードと同じく人に見せないでください。

定数表データを読み込み（グリッドが空のとき）

ジャケット一覧が出ない／「該当する譜面がありません」になる場合は、定数表データの自動取得が CORS でブロックされています。chunithm_record.json を開いて保存し、下で読み込んでください（一度読めば次回から自動）。

sdvx.in の曲一覧は JavaScript で動的生成され、ID（例: 07084）は曲名から計算できません。そのため、sdvx.in のページ上で下のスクリプトを一度だけ実行して曲名↔IDの対応表を取り出します（一度設定すれば保存されます）。

スコアを読み込み

自己ベスト（スコア・ランク・FC/AJ/AJC）をタイルに表示します。取得元は2通りあります。おすすめは①の公式で、新曲もプレイ直後から反映されます。

① CHUNITHM-NET（公式）から取得（おすすめ）

  1. 下の「🎮」ボタンをブックマークバーにドラッグして登録
  2. CHUNITHM-NET にログインし、ホーム画面を開く
  3. 登録したブックマークをクリック → 右上に進捗が出て、5難易度ぶん取得すると chunithm-scores.json が自動ダウンロード
  4. 下の「スコアJSONを読み込み」で選択

🎮 CHUNITHM-NETからスコアを書き出し ← ブックマークバーへドラッグ

※ chunirecのスコア更新と同じく、各難易度の記録ページを1回ずつ（計5回）読み込むだけです。

② chunirec から取得

  1. 下の「🏆」ボタンをブックマークバーに登録
  2. chunirec にログインし、自分のスコア一覧ページ（詳細表示）を開く
  3. 登録したブックマークをクリック → chunithm-scores.json が自動ダウンロード

🏆 chunirecスコアを書き出し ← ブックマークバーへドラッグ

スコアJSONを読み込み

①・②どちらで作ったファイルも、ここで読み込めます（読み込むと前のスコアは置き換わります）。

対応表の更新（2通り）

ゲームのアップデートで曲が増えたら、対応表を作り直します。方法①ブックマークレット（ワンクリック・おすすめ）か、方法②コンソールにスクリプトを貼る（従来）のどちらでもOKです。

方法①：ブックマークレット（ワンクリック更新）

  1. 下のボタンをブックマークバーにドラッグ＆ドロップして登録（スマホは長押し→ブックマーク追加）
  2. sdvx.in の譜面保管所を開く
  3. 下の2つのボタンをそれぞれブックマークバーにドラッグして登録
  4. 初回は「全件取得」、アップデートで曲が増えたら「差分更新」を使う
  5. 登録したブックマークをクリック → 右上に進捗、完了でJSONが自動ダウンロード
  6. このツールの「方法A」で読み込む（差分更新ぶんは既存に追記されます）

⚡ 全件取得（初回・作り直し） ← ブックマークバーへドラッグ

🔄 差分更新（最新2バージョンだけ・速い） ← ブックマークバーへドラッグ

※ ボタンはクリックではなくドラッグでブックマーク登録 → sdvx.in 上で使います。
「差分更新」は最新2バージョンだけ取得するので速いです（古い曲は変化しないため）。読み込みは既存に追記されるので、古い曲が消えることはありません。全部作り直したいときだけ「全件取得」を使ってください。

方法②：コンソールにスクリプトを貼る（従来）

手順

  1. https://sdvx.in/chunithm.html を新しいタブで開く
  2. ページが完全に表示されたら、F12 →「コンソール」タブを開く（PC推奨）
  3. 下のスクリプトを「コピー」してコンソールに貼り付け、Enter で実行
  4. chunithm-sdvx-map.json が自動ダウンロードされます
  5. 下の「方法A」でそのファイルを読み込む（コピペより確実です）
